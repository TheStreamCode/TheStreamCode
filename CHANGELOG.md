# Changelog

All notable changes to the profile page are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Repository hygiene files, CODEOWNERS, Dependabot configuration and a pull request template.
- `AGENTS.md` with the rules for editing the profile page.

### Changed

- Lead with distribution numbers and the community, and replace the unsupported backend claim with
  local-first applications.
- Add a reach column to the selected work table with the registry or store where each project ships.
- State the availability consistently with the CV, and label the language chart for what it measures.
- Replace the sponsor count badge with a static one while the count is zero.
- Drop the duplicated name heading and carry the numbers in a badge strip instead of prose.
- Replace the selected work table with a list, which no longer forces awkward wrapping at any width.
- Move selected work directly under the intro and collapse the contact list into one line.
- Remove the repository-language chart and its generation, keeping a single activity chart.
