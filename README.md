## Selected work

- **[super-cli](https://github.com/TheStreamCode/super-cli)**: one VS Code sidebar and terminal for more
  than 30 coding agents, with zero runtime dependencies and no telemetry. 10,500+ downloads on
  [Open VSX](https://open-vsx.org/extension/mikesoft/vscode-super-cli).
- **[chutes-build](https://github.com/TheStreamCode/chutes-build)**: privacy-first coding agent for the
  Chutes ecosystem, with no telemetry and no self-update. 3,000+ npm downloads per month.
- **[keysoft](https://github.com/TheStreamCode/keysoft)**: offline-first password manager for Android,
  with no accounts and no cloud. On
  [Google Play](https://play.google.com/store/apps/details?id=it.mikesoft.keysoft).
- **[mikesoft-teamvault](https://github.com/TheStreamCode/mikesoft-teamvault)**: private document
  management for WordPress with granular permissions and audit logs. 40+ active installs on
  [WordPress.org](https://wordpress.org/plugins/mikesoft-teamvault/).
- **[opencode-muse-auth](https://github.com/TheStreamCode/opencode-muse-auth)**: Muse Code authentication
  and model access for opencode. 1,500+ npm downloads per month.
- **[chutes-media-mcp](https://github.com/TheStreamCode/chutes-media-mcp)**: MCP server and CLI for image,
  video, music and speech generation. 400+ npm downloads per month.
