I've been building software and digital products for over ten years. Most of
that work happens outside GitHub — client projects, private products and the
commercial side of [Mikesoft](https://mikesoft.it/en/), an independent studio
where the person you talk to is the person who builds the product.

This profile is the public part of that work: open-source tools, extensions and
experiments that others can use, inspect and improve. I care less about labels
and stacks than about shipping software that is clear, useful and well made.

**Open to** freelance projects and collaborations. Building something
interesting? [Let's talk](mailto:info@mikesoft.it).
